# Shuning Li Personal Website

This folder contains a GitHub Pages-ready personal website for an economics Ph.D. job market profile.

## Files

- `index.html`: Website content.
- `styles.css`: Website styling.
- `main.pdf`: CV linked from the website.

## Suggested GitHub Pages Setup

1. Create a GitHub repository named `shuning-li.github.io` under the `lishn6` account.
2. Push `index.html`, `styles.css`, `main.pdf`, and this `README.md`.
3. In GitHub, open `Settings` > `Pages`.
4. Choose `Deploy from a branch`, then select the `main` branch and root folder.
5. After publishing, the project site should be available at `https://lishn6.github.io/shuning-li.github.io/`.
