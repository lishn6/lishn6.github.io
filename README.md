# Shuning Li Personal Website

This folder contains a simple GitHub Pages-ready personal website for an economics Ph.D. job market profile.

## Files

- `index.html`: Website content.
- `styles.css`: Website styling.
- `main.pdf`: CV linked from the website.

## Suggested GitHub Pages Setup

1. Create a GitHub repository named `shuning-li.github.io`.
2. Upload `index.html`, `styles.css`, and `main.pdf`.
3. In GitHub, open `Settings` > `Pages`.
4. Choose the main branch and root folder as the Pages source.
5. After publishing, the site will be available at `https://USERNAME.github.io/` for a user site, or `https://USERNAME.github.io/REPOSITORY/` for a project site.
